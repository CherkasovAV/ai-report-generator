# Безопасность

- **Не коммитьте** файл `.env` и любые файлы с API-ключами. В репозитории должен быть только **`.env.example`** (без реальных значений).
- Если ключ случайно попал в историю Git или в публичный репозиторий, **немедленно отзовите** его в кабинете провайдера (OpenAI, ProxyAPI и т.д.) и создайте новый.
- PDF в каталоге `reports/` по умолчанию **не попадают** в Git (см. `.gitignore`). Не публикуйте в issue вложения с персональными данными клиентов.

Сообщить о проблеме безопасности можно через Issues репозитория (без раскрытия секретов в тексте).
